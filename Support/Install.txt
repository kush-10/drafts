Drafts v0.9.1 — install on macOS 14 or later

1. Drag Drafts.app onto Applications.
2. Eject this disk image.
3. Open Drafts from Applications.
4. Press Option + Space to open your notepad; press again to save and hide.

Drafts is a menu-bar utility, so there is no Dock icon. The menu-bar icon can
be hidden in Settings. Open a note and press Command + comma to restore it.

PREVIEW BUILD / MACOS SECURITY WARNING

The current public preview is ad-hoc signed, not Apple-notarized. macOS may
say it cannot verify the developer or check the app for malicious software.

Only continue if you downloaded it from the official repository:
https://github.com/kush-10/drafts/releases

After trying to open the app, go to System Settings > Privacy & Security,
find the message about Drafts, choose Open Anyway, and confirm Open.
Your Mac may require administrator authentication. If your administrator
blocks this option, do not bypass their policy; build from source instead.

Do not disable Gatekeeper or remove quarantine from broad folders.
If macOS reports actual malware or a damaged/modified app, stop and verify
the download rather than overriding that warning.

Shortcuts

Option + Space          Show most recently edited note / save and hide
Command + N             New blank draft (reuses an existing blank)
Command + F             Expand to fill the display / restore previous size
Command + K             Search saved note text and topics
Option + Shift + K      Search notes from any app
Shift + Command + C     Copy the entire note as text and hide
Escape                  Dismiss search, or save and hide the note
Option + Shift + L      All notes in the notepad window
Command + comma         Settings

Switching apps or clicking outside keeps the notepad open. Hide it explicitly
with Option + Space, Escape, or Copy & close. If saving fails, it stays open.
Expansion uses the display's usable area without a separate full-screen Space.
Window size is remembered for 30 minutes by default, adjustable in Settings.

Optional local AI requires Apple Silicon. Select and download a model in
Settings > Models. No weights are bundled or downloaded automatically.
Writing and search work without AI; notes are never sent to a service.

Notes are stored only on this Mac:
~/Library/Application Support/Drafts/Notes/

Keep everything is the default storage policy. Automatic deletion is an
optional setting and is permanent when enabled. Back up important notes.
